## Decisions & deviations
- Kept as external contract, deliberately Portuguese: step values (`modelo`, `tudo`), `ESTUDIO_*` environment variables (`ESTUDIO_MODELO_MANIFESTO`, `ESTUDIO_DADOS` etc., shared with many tests and the transcriber), JSON keys, the on-disk folder `modelos/` (shared with `transcrever.py`), the script file names, and the tmp sub-folder `modelo`.
- PowerShell parameters `-Passo`/`-Dados` renamed to `-Step`/`-DataDir` (they are variables of the script; callers updated). Consequence: the `instalar.ps1` usage line printed on a usage error (stderr, seen by the Diretor, exit 2) has the two flag names changed; its pt-BR words are unchanged. This is the one intended difference from "byte-identical". `-Estudio` kept: glossary term.
- Non-identifier string literals renamed for tidiness: tmp folders `ffmpeg-pacote`/`ffmpeg-pronto` -> `ffmpeg-package`/`ffmpeg-ready` (deleted after each step), fallback folder `estudio-sem-dados` -> `estudio-no-data`.
- Bug caught on the way: the first sed pass missed the PowerShell splat `@Argumentos`, which made `Works` run the Python probe without arguments (the Windows hook test 19 failed); fixed by renaming to `@Arguments`, then all suites re-run.

## Learnings
- A rename by `sed` must cover PowerShell splats (`@Name`) as well as `$Name`; only a call that actually passes arguments through the function (the Python probe) shows the miss.
- `sh` dispatch built from a step name (`"instala_$STEP"`) couples function names to user-facing step names; a `case` decouples them.
- `gh issue view` fails on this repo (Projects classic); use `gh api repos/rodrigorjsf/studio/issues/N`. `npm` is broken here; run `node node_modules/typescript/bin/tsc` and `node --test` directly with a temporary node_modules symlink.
