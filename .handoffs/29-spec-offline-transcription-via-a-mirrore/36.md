## Decisions & deviations
- **Mismatches found in the sources** (not fixed, docs-only ticket):
  1. `plano/SKILL.md` step 5 says the second Gate (Quadros) is asked "as in step 4", whose "changes" branch hands the notes to the Roteirista; but the Quadros are drawn by the Diretor de arte. The README says the notes "voltam ao trabalho" for the two-Gate case without naming who redraws.
  2. `edicao/SKILL.md` step 5.3 caps the Entrega QC loop with "the same cap as step 2 item 3" (see it or follow a direction), but `entregar` blocks a failed QC, so "ver assim mesmo" cannot deliver. The diagram gives the Entrega escalation only the "uma direção sua" exit.
  3. `perfil/SKILL.md` describes Autonomia média as approving nothing but the Kit answering briefing questions; the CLI (`autonomia.mjs`) confirms no Gate is automatic for média. Consistent, no README change.
  4. The Diretor is four skills (`estudio`, `novo-video`, `plano`, `edicao`) and the Entrevistador four (`perfil`, `novo-projeto`, `editar-projeto`, briefing in `novo-video`); the table lists them as one persona each, as `CONTEXT.md` does.
- **Animated edges not added.** I could not verify that github.com's Mermaid supports `e1@{ animate: true }`; if unsupported the whole diagram would fail. The ticket says "where the renderer supports them"; the existing README diagram has none either.
- The Preparação and "Criar o Estúdio" questions are included as Gates (she approves both) although they sit outside a Vídeo's Esteira.
- `wiki/overview.md` and `wiki/index.md` got one sync line each (wiki-sync rule).
