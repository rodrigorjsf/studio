## What was built
- `plugin/estudio/hosts.json`: the one list of every host the Preparação reaches: `github.com`, `release-assets.githubusercontent.com` (where GitHub Release downloads redirect), `nodejs.org`, `ffmpeg.martin-riedl.de`, `releases.astral.sh` (the Python uv downloads), `pypi.org`, `files.pythonhosted.org`, `registry.npmjs.org`. - `getting-started.md`, section "If a Preparação download is blocked": given only after a download failed, never up front; Settings → Capabilities (Configurações → Recursos), network access / allowed domains, add every host of `hosts.json` in one message, "tenta de novo"; Team/Enterprise: only an admin, Admin settings → Capabilities. `estudio/SKILL.md` links a failed download step to it.
