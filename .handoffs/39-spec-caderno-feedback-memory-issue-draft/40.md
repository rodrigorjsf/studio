## What was built
- New CLI command `caderno` (`plugin/estudio/scripts/lib/caderno.mjs`): appends an entry (layer, section, text, persona, optional Vídeo, date stamped), replaces or removes one by identifier, and refuses unknown layer, section, Projeto, Vídeo or entry with a stable `reason`, changing no file.
- The Caderno is pt-BR markdown: `caderno.md` at the Estúdio root and in each Projeto folder, sections Elogios / Queixas / Soluções.
- `estado` reports `caderno: {caminho, existe}` for the Estúdio and for each Projeto (absolute paths).
- Diretor skills (`estudio`, `novo-video`, `plano`, `edicao`) and a new reference `skills/estudio/references/caderno.md` cover reading, capture with a one-line notice, layer choice, conflict resolution, the Kit learning offer and handling persona proposals.
- All 11 persona prompts get a "The Caderno" section: `<caderno-estudio>`, `<caderno-projeto>`, read first, optional `caderno-proposto` report field. README actors section and wiki updated.

## Decisions & deviations
- JSON input: `acao` anexar|substituir|remover; `camada` estudio|projeto; `secao` elogios|queixas|solucoes; `projeto` required for the projeto layer; `video` optional and needs `projeto`. Refusal codes: `unknown-layer`, `unknown-section`, `unknown-projeto`, `unknown-video`, `unknown-entry`, `invalid-input`, `not-estudio`.
- Identifiers are per file, never reused (counter comment `<!-- proximo: N -->` under the title). Date is her local date.
- `substituir` re-stamps persona, Vídeo and date; the Diretor passes them again.
- `estado` returns `{caminho, existe}` rather than a bare path, so the Diretor knows whether to read.
- Caderno file is created lazily on first entry. Personas have no write path to it.
- Not red-first: the refusal tests and some static tests passed on first run because the code was written in an earlier slice; persona/skill/README static tests were verified red by stashing the prompts.
- Existing tests that deep-equal the `estado` Projeto shape (`tests/estado.test.mjs`, `tests/projeto.test.mjs`) now include `caderno`.
