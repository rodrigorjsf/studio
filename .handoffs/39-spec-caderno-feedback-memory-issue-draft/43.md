## What was built
- New CLI command `rascunho-issue` (`plugin/estudio/scripts/lib/rascunho-issue.mjs`): `salvar` writes a draft to `issues/NNN-<slug>.md` at the Estúdio root and returns the pre-filled `https://github.com/rodrigorjsf/studio/issues/new?title=…&body=…` link (encoded); `link` returns titulo, corpo and link; `decidir` records `publicado` (with the issue URL), `link-entregue` or `recusado`, once.
- It refuses a draft whose title or body contains the Estúdio's absolute path (also through a symlink) or the name of any Projeto or Vídeo (`private-content`), and refuses every malformed input with a stable `reason`, changing no file.
- `estado` reports `rascunhosPendentes` (drafts with no decision); a damaged draft file is an `errors` entry.

## Decisions & deviations
- JSON input: `acao` salvar|link|decidir; `tipo` `bug`|`evolucao`; `decisao` publicado|link-entregue|recusado; `url` only with `publicado` and only `https://github.com/rodrigorjsf/studio/issues/<n>`. Refusal codes: `private-content` (with `encontrados`), `unknown-kind`, `unknown-draft`, `already-decided`, `invalid-input`, `not-estudio`.
- The issues folder is `issues/` at the Estúdio root (ADR 0007). A draft is one markdown file with frontmatter (id, tipo, titulo, criadoEm, decisao, decididoEm, url); the file name number is its identifier and must match the frontmatter id.
- Privacy check is a plain case-insensitive substring match, composed (NFC), `\` read as `/`. A short Projeto name can trip on an ordinary word; the reference tells the Diretor to rephrase. Chosen over word-boundary matching because a near-miss leak (an inflected name) is worse than a rephrase.
- Additions beyond the ticket text: `link` re-checks privacy (the link is what leaves her computer); `linkCabe` flags links over 7,000 characters so the Diretor hands the body instead; `estudio` skill rule to save a draft for a plugin defect whenever noticed, not only at the close.
- edicao step 6 was reordered: the Caderno write moved ahead of the Kit question (drafts are counted from the Caderno), then the two questions, then `arquivar`. The drafts Gate is asked after the Entrega and is not counted in the Vídeo's metrics, like the Kit question.
- Publishing with `gh` uses a temporary `--body-file` (shell-safe) rather than `--body`.
- Not red-first: the first two slices (save, link) were written red then green; the `estado` and unknown-draft checks were red first; the "unknown-draft for decidir" and "acao unknown" refusals passed early through a stub.

## Learnings
- Worktree has no `node_modules`; symlink the main checkout's (`ln -s`) to run typecheck, delete it before the status check.
