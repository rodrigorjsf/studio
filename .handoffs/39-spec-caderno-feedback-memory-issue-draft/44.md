## What was built
- New persona `social-media` (`plugin/estudio/agents/social-media.md`): Sonnet 5.5, medium effort, tools Bash, Read, Write, color cyan. It reads the briefing, transcript, Plano, Kit (`plataformas`), Perfil, both Cadernos, the Resumos Notion and the bundled platform reference, and writes `entrega/texto-do-post.md`: one `## ` section per platform (Reels, TikTok, Shorts), with a keyword first line, a short honest text, at most one genuine question or call to action, specific hashtags and, for Shorts, a `**Título:**` line. It reruns `texto-do-post` until it passes, three rounds at most.
- New CLI command `texto-do-post` (`plugin/estudio/scripts/lib/texto-do-post.mjs`): returns `problemas` and `pronto`. It rejects a missing platform of the Kit's list, an extra one, more than 5 Instagram hashtags, more than 60 on any platform, a Shorts title over 100 characters or holding a hashtag, and every filler tag (`#fyp`, `#foryou`, `#viral`, `#explore`, `#reels`, `#trending`, plus `#fypage`, `#foryoupage`, `#explorepage`).
- The edicao skill (Entrega step 2) starts the Social media in parallel with the Finalizador, and the close (step 5, item 6) shows one copy-ready block per platform with the "check each hashtag in the app" note, a line when `estado` says the reference is stale, and the rule never to call it "legenda".
- README actors table (new row, "doze agentes"), the call-chain diagram and a "Texto do post" bullet; wiki pages, log and `docs/developer-guide.md` updated.

## Decisions & deviations
- File name and format: `entrega/texto-do-post.md` (the name the wiki and ADR 0008 give), `## Reels` / `## TikTok` / `## Shorts` headings (aliases `Instagram`, `YouTube`, `YouTube Shorts` accepted), title as `**Título:** …`. Constant `TEXTO_DO_POST` in `layout.mjs`.
- Refusals: `no-texto`, `invalid-kit` (unreadable Kit, or a `plataformas` that is empty, not a list, or names an unknown platform), `unknown-projeto`, `unknown-video`. The command follows the Vídeo's own `kit.json` when it has one, else the Projeto's, like `plano`.
- Beyond the ticket's list, the command also rejects a section with no text, a Shorts section with no title, and a duplicated section: they follow from "each section has …". Flagged by review as minor scope; kept.
- Hashtags are counted by occurrence (a repeated tag counts each time); two glued tags (`#a#fyp`) count as two. The 5-tag cap applies to Reels only; the 60 cap to every platform, as the ticket says although the reference states it for YouTube.
- The filler list extends the ticket's with `fypage`, `foryoupage`, `explorepage` (the last is `[marketing]` in the reference); the Shorts title length is also `[marketing]` there. Both are the ticket's own rules, so the command comment says what it really enforces.
- Closing message: when `texto-do-post` is not `pronto` after the persona's rounds, the Diretor withholds the text, tells her the video is delivered but the post text is not ready, and offers a retry. The ticket is silent; the escalation loop with the Revisor is ticket #45's.
- The stale-reference warning is the Diretor's (from `estado.referenciaDePlataforma.desatualizada`), since the persona never talks to her; the persona does not write the hashtag note or the warning into the file.
- `PLATAFORMAS` is now exported from `kit.mjs` (handoff #41 suggested it) so the command's platform table keys off the one list.
- Not red-first for the persona and docs static tests beyond the initial missing file; the CLI tests were red (17 of 18 failed) before `texto-do-post.mjs` existed.
