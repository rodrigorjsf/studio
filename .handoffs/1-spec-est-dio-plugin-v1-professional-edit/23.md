## Decisions & deviations
- **The vendored files are fully verbatim, `__main__` CLI included.** They are not trimmed, so the sha256 matches upstream and stays checkable. `THIRD_PARTY.md` says the CLI is kept but unused. They carry no download code.
- **The bytes come from `git show <sha>:path`, not from the checkout,** because global `autocrlf` makes the checkout CRLF. `.gitattributes` gains `plugin/estudio/scripts/frames/** -text` so the bytes never convert.
- **`vendor.json` stores `owner`/`repo` as separate fields,** so the literal `bradautomates/claude-video` appears only in `THIRD_PARTY.md`. `vendor.json` is also exempt from the "invokes watch" pattern, because it records upstream paths such as `skills/watch/...`.
- **CLI vocabulary:** the modes use pt-BR domain terms (`visao-geral`, `zona-do-rosto`), and the flags keep upstream's names (`--start`, `--end`, `--max-frames`, `--fps`, `--resolution`, `--cues`).
- **ffmpeg on PATH:** `amostrar.py` prepends the directories of the `--ffmpeg`/`--ffprobe` paths to PATH, because frames.py calls them by name. It checks that they resolve first, so upstream's "brew install" error never reaches the Diretor. It also sets `sys.dont_write_bytecode`, and `.gitignore` gains `__pycache__/`.
- **The sampler command lives in `SKILL.md`,** where `${CLAUDE_PLUGIN_ROOT}` is substituted. Reference files are read raw, so they point to that section instead of repeating the command.
- **Upstream mistakes corrected in the Remotion references:**
  - `trimBefore`/`trimAfter` are in frames;
  - `getImageDimensions` is in `@remotion/media-utils`;
  - Mediabunny has `BlobSource`, not `FileSource`;
  - transparent WebM is vp9, not vp8.
- **Pinning rule in the references:** extra `@remotion/*` packages are added through `npx remotion add`, which pins to the installed version (verified in the `@remotion/cli` source).
- **The default `npm test` skips the 5 sampler tests** on a machine without an installed data folder, including the integrator's run. They were run for real with `ESTUDIO_DADOS=/tmp/estudio-dados-23`, a data folder filled by `instalar.sh ffmpeg` and `instalar.sh python` during this run.

## Learnings
- Global `core.autocrlf=true` also converts `/tmp` clones. Take vendored bytes with `git show <sha>:<path>` and mark them `-text`.
- `${CLAUDE_PLUGIN_ROOT}` is substituted only in SKILL.md bodies, not in reference files the model reads. Put runnable commands in SKILL.md.
- Upstream Remotion skill rules at v4.0.451 contain API mistakes. Always grep the `.d.ts` before citing an API.
- The lavfi color+concat clip of 2×1.5 s comes out 3.04 s long. Assert against the probed duration, not the nominal one.
