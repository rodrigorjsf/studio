## What was built
- **Credit Gate `aprovar-creditos`** (`plugin/estudio/scripts/lib/creditos.mjs`). It applies to a Nível 2 Vídeo whose Plano is approved, and takes `{saldo, creditosEstimados?}`.
  - It checks her balance, read by the Diretor with the connector's `balance`, against the estimate minus what is already spent.
  - It checks the Kit's `creditos.porVideo`, and `porMes`, which also counts the Projeto's other Vídeos approved this calendar month (UTC).
  - It records `creditosEstimados` and `creditosAprovadosEm` in `video.md` and counts one Gate. Autonomia never approves credits.
- **Pre-spend check `gastar-creditos`**, run before every generation is paid. It takes exactly `{arquivo, creditos, saldo, modelo, prompt}`.
  - It refuses without the Gate, while a Gate is open or a stop is latched, when the balance does not cover the cost, when the prompt lacks `no text`/`sem texto`, and for a duplicate file or one outside `gerados/`.
  - The spend that would pass the estimate × 1.2 is refused (`over-limit`). That opens the Gate and latches `creditosParadosEm`, and only a new `aprovar-creditos` lifts the stop.
  - An authorized spend adds to `creditosGastos` and appends to `gerados/gerados.json`.
- **Persona `agents/artista-generativo.md`** (claude-sonnet-5-5, high). Its tools are Bash, Read, `mcp__claude_ai_Higgsfield` and `mcp__higgsfield`. It generates the images and clips into the Vídeo's `gerados/` folder and redoes any image that shows text.
- **Template:** `<Gerado>` and `arquivoDoVideo` in `template/src/_shared/edicao.tsx`. `<Gerado>` shows a generated image or clip full-frame, and a clip is always muted.
- **Skills:** `plano` step 4 shows her balance next to the credits and holds the credit Gate. `edicao` step 2 runs the Artista before the Motion designer and handles a stop. `motion-designer` uses `<Gerado>`, and `roteirista-estrategista` estimates the credits.
- **Reference:** `level-2-higgsfield.md` was rewritten for ADR 0002: the connector only, montage in Remotion, no API key, no `edicoes/` or `edit.jsx`.
- **Structure check:** `scripts/check-plugin.mjs` rejects a package that names `HF_KEY`, `HF_API_KEY`, `HF_API_SECRET` or `hf_api.py`.

## Decisions & deviations
- **"Spent" is the sum of the connector's quoted costs**, passed by the Artista before each submit, with the balance read again each time. Actual charges are not reconciled with the quotes, and a failed job still counts, which errs on the safe side. The end-to-end run (#19) will show whether quotes drift.
- **The credit Gate is its own Gate.** It is asked in the same question as the Plano's Gate, but `gates` counts +1 for it, because it is the one Gate Autonomia can never approve.
- **The Kit budget is enforced** (`over-budget`, per Vídeo and per month). This covers spec story 29, which is not in the ticket's acceptance criteria.
- **Assets go in `gerados/`**, not the upstream `hf/`, and the ledger is `gerados/gerados.json`.
- **The Artista's Higgsfield tools are server-level names**, which the docs say `tools:` accepts. The claude.ai connector prefix `mcp__claude_ai_Higgsfield` is inferred from how other connectors are named in this environment. It is not verified end to end and should be confirmed in #19.
- **Higgsedit on request is only mentioned** in the reference, and deferred to #16.

## Learnings
- Template files are CRLF in this WSL clone, so tests that rewrite `Root.tsx` must match `\r?\n`.
- A child placed after `<Video>` inside `AbsoluteFill` is pushed below the frame (flex column). Wrap overlays in `AbsoluteFill`.
- Subagent `tools:` accepts server-level MCP names (`mcp__server`), but no wildcards.
