## What was built
- The Estúdio's Remotion template now reads each Projeto's `kit.json`. The loader is `plugin/estudio/template/src/_shared/kit.ts`. `calcularMetadadosDoKit` fetches `projetos/<projeto>/kit.json` from the public folder, sizes the frame from the Formato, and hands the Kit to the component as the `kit` prop.
- The props are `{projeto, formato}`:
  - `formato: null` gives the Kit's Formato, which is 9:16 (1080×1920) by default.
  - `"16:9"` (1920×1080) or `"1:1"` renders the same composition as a variant on request.
  - `projeto: ''` gives the default Kit.
- The brand pieces live in `plugin/estudio/template/src/_shared/marca.tsx`:
  - `estiloDaFonte` applies the family and weight.
  - `useFontesDoKit` loads the font files stored under `kit/` through FontFace and delayRender.
  - `useEntradaDoKit` runs the entrance over `movimento.entradaMs`.
  - `LegendaDoKit` draws captions in the Kit's style: `palavrasPorVez` grouping, highlight, position, case, font and size.
- A new composition, `PreviaDoKit` ("Prévia do Kit", in `src/kit/PreviaDoKit.tsx`), is registered in `Root.tsx` under the folder "Kit". It draws a Kit on one frame and is the worked example for the Vídeo compositions that come later.
- The default Kit now has a single source, `template/src/_shared/kit-padrao.json`. `lib/kit.mjs` `defaultKit()` reads it, so `novo-projeto` and the template cannot drift apart.

## Decisions & deviations
- **The Kit is loaded at render time from the public folder** (`staticFile`), rather than imported at build time. One template then serves every Projeto in the Estúdio, selected by the `projeto` prop.
- **The default Formato comes from the Kit.** 9:16 is the Kit's default, so a Kit where she chose 16:9 renders 16:9 by default. The spec reviewer agreed with this reading.
- **The gallery examples in `template/src/estilos/` keep their own hex palettes.** They show a style, not a Projeto's brand, and `Root.tsx` says so in a comment. The rule "no brand value in a Vídeo's code" is documented in `level-1-remotion.md`. It is not enforced; see follow-up #24.
- **`defaultKit()` now reads `template/src/_shared/kit-padrao.json`,** with a path hard-coded inside the plugin. The content is unchanged.
- **Two compiler options were added** to both tsconfigs (repo and template): `resolveJsonModule`, and `DOM.Iterable` for `document.fonts.add`.
- **The Kit reads only some motion and caption fields:**
  - Motion: only `movimento.entradaMs` is consumed. `intensidade`, `ritmo` and `transicao` are editorial inputs for the Plano (#10) and the build (#11); they are typed in `kit.ts`.
  - Captions: `legendas.estilo` highlights the spoken word only for `palavra-destacada`. Any other style draws the group in one color.
- **"Prévia do Kit" is a new glossary term in `CONTEXT.md`.** It is distinguished from Quadro de estilo.
- **Loading font files (`tipografia.*.arquivo`) is typechecked but not covered by a render test.** The test would need a binary font fixture.
