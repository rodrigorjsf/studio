## What was built
- `/estudio:novo-video` (`plugin/estudio/skills/novo-video/SKILL.md`). The Diretor, playing the Entrevistador for the briefing step:
  - picks a Projeto whose Kit is approved;
  - takes exactly one recording per Vídeo;
  - asks only objetivo, chamada para ação, momentos-chave, "o que muda do Kit" (with the Kit's empty text fields folded in) and the Nível;
  - records the Nível and the question count, names the missing Prints with reasons, then moves the Vídeo to `Planejamento`.
- New CLI subcommands in `plugin/estudio/scripts/estudio.mjs` (code in `lib/video.mjs` and `lib/ingest.mjs`):
  - `novo-video` copies the recording byte for byte into `videos/<vídeo>/original/`. Her own file stays put, and an existing Vídeo is never given a second recording. It writes `video.md` (the record in the frontmatter, the pt-BR briefing sections in the body) and creates `prints/`, `frames/visao-geral/` and `frames/zona-do-rosto/`.
  - `registrar-video` records the Nível, a Status and increments to the counters.
  - `zona-do-rosto` joins the face measured on each frame into `zona-do-rosto.json`.
- Persona `plugin/estudio/agents/assistente-de-edicao.md` (`claude-sonnet-5-5`, effort `high`, tools Bash/Read/Write):
  - transcribes the video;
  - samples it for an overview and for the face zone, and measures the face on every frame;
  - returns a report that includes the Prints that would help.
- Transcriber `plugin/estudio/scripts/transcrever.py`:
  - uses faster-whisper;
  - keeps the model in the `--modelos` folder, which is inside the plugin data folder;
  - passes the Kit `glossario` to the model as a spelling hint;
  - writes `palavras.json` and `transcript.md`.
- `estado` now reports two new fields per Vídeo:
  - `briefing` (`completo` / `incompleto`);
  - `ingest.{transcricao, zonaDoRosto}`.

  It also validates the counters, the timestamps, `palavras.json` and `zona-do-rosto.json`.

## Decisions & deviations
- **The recording is copied, not moved,** so her own file is never touched. `COPYFILE_EXCL` guards against overwriting. The cost is that the recording takes twice the disk space.
- **The face is measured by the Assistente de edição reading the frames; the CLI only checks and aggregates.** No face-detection library is installed, because that would widen the #4 installer.
  - The zone is the union of the measured boxes, plus a margin of 0.05 of the frame on each side, clamped to the frame. It is `null` when no frame shows a face.
  - The zone is accepted only from a face-zone sampler run (`modo: zona-do-rosto`, `dedup: false`). No gap between frames may exceed max(1 s, duration/600), which mirrors the constants in `amostrar.py`. Every frame must also be measured.
- **Only one briefing placeholder:** the Vídeo briefing reuses `_A preencher na entrevista._` (exported as `PLACEHOLDER` from `briefing.mjs`).
- **Kit gaps** are the Kit's text fields that are exactly `""` (`lacunasDoKit`). Nothing else from the Kit is asked again.
- **The Vídeo record's field names:**
  - `nivel`, `rodada`, `gate`, `original`, `master` (= the Original until a Pré-corte);
  - `creditosEstimados`, `creditosGastos`;
  - `perguntas`, `gates`, `aprovacoesAutomaticas`;
  - `iniciadoEm`, `entregueEm`.

  There is no separate "Rodadas" counter: `rodada`, the current Rodada, is also the count.
- **The Nível moves from session start into each Vídeo briefing.** The entry skill now defers the Nível question to `novo-video` when she starts a Vídeo.
- **Absorbed an installer fix: the installers now pin `faster-whisper==1.2.1 "av<19"`** (`instalar.sh`, `instalar.ps1`). PyAV 19 breaks every faster-whisper 1.2.1 transcription with `open() got an unexpected keyword argument 'metadata_errors'`. Versions 16–18 work, checked on this machine.
- **The Notion question in the briefing** is left as a pending note for #20.

## Learnings
- PyAV 19 breaks faster-whisper 1.2.1. Pin `av<19` until faster-whisper releases a fix.
- A plugin data folder installed before this ticket (e.g. `/tmp/estudio-dados-23`) still has av 19. The check sees faster-whisper and says it is ready, so reinstall that folder's Python.
- `amostrar.py` needs its output directory to exist before a shell `>` redirect into it. `novo-video` creates it up front.
