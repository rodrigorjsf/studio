## What was built
- A deterministic CLI, `plugin/estudio/scripts/estudio.mjs`. It prints JSON on stdout. On a usage error or a missing folder it exits 2 with `{error}`. It has two subcommands:
  - `criar "<folder>"` turns a folder into an Estúdio. It writes the marker `estudio.json` (`{schemaVersion: 1, createdAt}`) and a `projetos/` folder, and copies in the Remotion template from `plugin/estudio/template/`. It never overwrites a file. On an existing Estúdio it refuses and returns `{created:false, reason:"already-estudio"}`.
  - `estado "<folder>"` validates the marker, `perfil.md`, each `projetos/<p>/{projeto.md,kit.json}` and each `projetos/<p>/videos/<v>/video.md`. It returns `isEstudio`, `isEmpty`, `errors[{file,message}]`, `perfil.present`, `projetos[{id,kit,videos[{id,status,rodada,nivel,waitingForCriadora}]}]`, `waiting[]` and a single `nextStep`.
- The `/estudio:estudio` skill now runs `estado` before its first reply and treats that output as its only source of state.
  - When the folder is not an Estúdio, it offers the scaffold with a single "sim / agora não" question.
  - On a "sim" it runs `criar`.

## Decisions & deviations
- **The CLI has one entry point with two subcommands.** It lives at `plugin/estudio/scripts/estudio.mjs` and has no top-level `bin/`. Its modules are:
  - `lib/layout.mjs`: the layout contract, the single place that names the files;
  - `lib/estado.mjs`;
  - `lib/criar.mjs`;
  - `lib/frontmatter.mjs`: a dependency-free parser for flat `key: value`, `- item` lists, numbers, booleans and quotes.
- **The scaffold command is named `criar`.** The spec lists only estado/qc/precorte, but the scaffold has to be deterministic too.
- **Layout:**
  - `estudio.json`
  - `perfil.md`
  - `projetos/<projeto>/projeto.md`
  - `projetos/<projeto>/kit.json`
  - `projetos/<projeto>/videos/<vídeo>/video.md`
  - `projetos/` is also the Remotion public dir.
  - Unknown files and folders are never rejected. That leaves room for `notion/` (#20), Kit assets, the Original and versions.
- **Validation is deliberately minimal:**
  - the marker must be JSON with `schemaVersion === 1`;
  - `perfil.md` and `projeto.md` must have parseable frontmatter;
  - `kit.json` must be a JSON object (`kit`: `ok` / `pendente` when absent / `invalido`);
  - `video.md` must have a valid `status` (one of the 9 CONTEXT.md values), a whole-number `rodada` and a `nivel` of 1 or 2.
  - The full Perfil, Kit and Vídeo schemas belong to #5, #6 and #9.
- **Whose turn each Status is:**
  - Briefing and Revisão wait for the Criadora.
  - Entregue and Arquivado are finished.
  - Every other Status is the studio's turn.
  - A new optional frontmatter field, `gate: aberto`, marks a non-finished Vídeo as waiting for her. The Plano, credit and Quadros Gates need it, and #9 and #10 should set it.
- **`nextStep.action` values, in this precedence:**
  1. `criar-estudio`
  2. `corrigir-erros`
  3. `perfil`
  4. `novo-projeto`
  5. `concluir-projeto` (Kit missing)
  6. `continuar-video` (Vídeos waiting for her first, then Vídeos in progress)
  7. `novo-video`
- **Hidden files** (`.DS_Store`, `.claude`) and `Thumbs.db`/`desktop.ini` don't count against `isEmpty`.
- **`criar` is also allowed in a non-empty folder** she chose. Her files are kept, and the skill tells her so.
- **The Remotion template** in `plugin/estudio/template/` is a copy of the repo's `src/`. Only comments changed, to point at the new layout. The copy keeps the synchronized-split primitive and the example styles. Per-Kit reading is #8.
  - The repo's `tsconfig.json` and `scripts/check-split-layouts.mjs` now also cover the template, so the shipped code is typechecked and guarded.
- **Pending markers in the skill point at issue numbers:** #5 (Perfil), #6 (Projeto/Kit), #9 (new Vídeo).
- The metric averages in `estado` are left to #17.

## Learnings
- `${CLAUDE_PLUGIN_ROOT}` inside a SKILL.md bash block is substituted inline when the skill loads. Verified with `claude -p --plugin-dir`.
- The worktree has `core.autocrlf=true`, so the frontmatter parser must accept `\r\n`.
- `rm -rf "$(mktemp -d)"` is blocked by the safety check. Use literal temp paths.
