## What was built
- **New skill `/estudio:edicao`** (`plugin/estudio/skills/edicao/SKILL.md`), for a Vídeo in `Construção`, `QC interno`, `Revisão`, `Ajustes` or `Aprovado`. The steps:
  1. The Motion designer builds a version.
  2. The Diretor opens her review on the key stills.
  3. She decides: aprovar, aprovar com pequenos ajustes, or pedir mudanças. Her notes are consolidated into one list, and scope changes are named.
  4. The Finalizador renders into `entrega/` and runs `entregar`.
  5. The Diretor opens the delivery folder with the `abrir` command that `entregar` returns.

## Decisions & deviations
- **`rodada` = the number of the version on show.** It is set by `abrir-revisao`, and it also counts the Rodadas. I added no separate counter.
- **Gates are counted on the decision** (`decidir-revisao`: gates +1), the same as `aprovar-plano`. Opening the review does not count one.
- **`aprovar-com-ajustes` goes straight to `Aprovado`,** with no new Rodada or version.
  - Its fixes are listed in `ajustesAntesDaEntrega`.
  - The Motion designer applies them and renders the stills they change into `revisao/vNN/ajustes/`, so the delivered edit stays versioned.
  - A scope change is refused under this decision (`scope-change`).
- **Opening the folder:** `entregar` returns the command instead of running it, so it stays deterministic and testable. The skill runs it.
  - In WSL it returns `explorer.exe` with `wslpath -w`. Explorer exits 1 even on success, and the skill says so.
- **`entregar` checks only what this ticket's acceptance criteria require:**
  - the video stream's duration within 1/fps + 1 ms of the Master. The container duration is not used, because AAC adds about 48 ms;
  - exactly one audio track per MP4 and none per MOV overlay;
  - at least one MP4.

  Resolution, loudness and the rest belong to `qc` (#12), which should be wired into `entregar`. That is marked pending in the skill.
- **The Master's duration is probed from the `master` file,** never taken from `zona-do-rosto.json`. That file is measured on the Original, which is wrong after a Pré-corte.
- **Remotion adds a silent audio track unless `--muted` is passed,** so overlays are rendered with `--muted`.
- **Deliverables follow the Kit's `entregaveis.formatos`/`overlays`**, plus her requests for this Vídeo.
- **The review can open from `QC interno`,** so #13 fits in without touching this code.

## Learnings
- A Remotion render always carries an audio track (silent). Pass `--muted` for overlays.
- A Remotion MP4's AAC makes the format duration about 48 ms longer than the video. Compare video stream durations.
- A second `@remotion/media` `<Video>` with the same src did not double the audio. `<Audio>` did (+6 dB).
- The `node_modules/` gitignore pattern does not match a symlink. Remove the worktree symlink before checking status.
