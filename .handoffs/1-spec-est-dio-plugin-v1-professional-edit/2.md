## Decisions & deviations
- **Marketplace name is `studio`**, after the repo, so the install id is `estudio@studio`. The spec doesn't fix it.
- **Crítico identification is by agent `name`, or by file basename when `name` is absent.** The names are `qc-tecnico`, `guardiao-da-marca` and `revisor-de-plataforma`. A Crítico must declare an explicit `tools` allowlist, because omitting it inherits every tool. The allowlist must not include Edit, Write, MultiEdit or NotebookEdit. **Bash is allowed** (judgement call), because QC técnico must run `qc`.
- **Personas must pin a full model ID.** `model` must start with `claude-`; aliases such as `opus`, `sonnet` and `inherit` are rejected. `effort` must be present.
- **Development material means the following:**
  - at the package top level: `wiki/`, `raw/`, `estado/`, `tests/`, `test/`, `bin/`, `PROJETO.md`, `GLOSSARIO.md`, `ROADMAP.md`;
  - anywhere: `node_modules`, `.git`, `*.test.*`, `*.spec.*`, `*.seam.*`.
- **Limits are 5,000 files and 200 MB**, from ADR 0005.
- **Added a relative-link check.** Every relative link, anchor included, must resolve inside the package. This enforces the Workspace rule "plugin artifacts are self-contained".
- **The persona in SKILL.md is the upstream CLAUDE.md persona, translated.** Steps owned by later tickets carry `Pending: ticket #3/#4` markers: the Estúdio folder and `estado` (#3), and the installer (#4).
- Root `CLAUDE.md`, `README.md`, `guias/` and `estilos/` are untouched. Their cleanup belongs to #18.
- `/estudio:estudio` has no `model`/`effort` frontmatter. The spec pins the main-session Diretor to Opus 5.5 `medium`, but this ticket's criteria don't require it.

## Learnings
- RTK-wrapped `npm test` / `npm ci` dropped the output summary, and one `npm ci` silently produced no `node_modules`. Use `/usr/bin/npm`. I didn't edit the RTK deny list, because it lives outside the worktree.
- `git stash` in a worktree writes the shared `refs/stash`, so never use it inside run-spec worktrees.
- Node 22 `node --test tests/` treats the directory as a module. Use the glob `"tests/**/*.test.mjs"`.
- `CLAUDE_CONFIG_DIR=<tmp>` isolates `claude plugin marketplace add/install` from `~/.claude`.

## Notes for dependent tickets
- Persona files go in `plugin/estudio/agents/<name>.md`. Each needs `model: claude-…` (a full ID) and `effort:`.
- Críticos must be named exactly `qc-tecnico`, `guardiao-da-marca` and `revisor-de-plataforma`. Each needs an explicit `tools:` list without Edit/Write/MultiEdit/NotebookEdit.
- `claude plugin validate --strict` accepts `effort` in agent frontmatter.
- New skills go in `plugin/estudio/skills/<name>/SKILL.md`. Links must stay inside `plugin/estudio/`, or `npm test` fails.
- Keep dev tooling (scripts, tests) outside `plugin/estudio/`. The deterministic CLI must not be a top-level `bin/`.
- References live at `plugin/estudio/skills/estudio/references/`. Their "Pending: ticket #3/#4" markers and upstream-layout notes should be updated when those tickets land.
