# Platform rules for the Texto do post are bundled and dated, not researched live

A new persona, the **Social media**, writes each approved Vídeo's **Texto do post** (first line, text, hashtags and, for Shorts, the title) for the platforms listed in the Kit's new `plataformas` field. It runs beside the Finalizador, writes `entrega/texto-do-post.md` (`entregar` only checks MP4 and MOV files), and needs no Gate; the Diretor also shows it in the closing message, ready to copy. The Revisor de plataforma is its Crítico.

The rules it follows are a reference file bundled **inside the plugin**, condensed from the 2026-09-30 research (`raw/research/post-copy-and-hashtags-2026/findings.md`) and citing the platform URLs directly. It is not a pointer to that research, since the package cannot reference repo docs. Each rule carries its source label (official, study, marketing) and a `sourced:` date. When the file is older than 6 months, the Social media warns the Criadora; the maintainer refreshes it quarterly.

- **Why not live web research per Vídeo:** her network may be an allowlist ([0006](0006-speech-model-mirrored-and-fetched-in-preparacao.md)), live research costs tokens every Vídeo, and results drift from run to run.
- **Why the Crítico rejects only on official rules:** the Revisor de plataforma rejects on bright-line, official rules only. Those are Instagram's 5-hashtag cap, YouTube ignoring every hashtag past 60, engagement bait, filler tags such as `#fyp`, `#foryou`, `#viral` and `#explore`, and claims that are not in the transcript. Counts and lengths from marketing sources ("3–5 TikTok hashtags", "first line under ~100 characters") are guidance for the Social media, not rejection codes, so folklore never blocks a good post.

Cost: the file goes stale silently if the maintainer skips the refresh; the 6-month warning is the only guard.
