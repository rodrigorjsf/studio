# Dependencies install without admin rights, into the plugin's data folder

Remotion, ffmpeg and faster-whisper need Node, ffmpeg and Python on the Criadora's Mac or Windows machine. The Claude Desktop Code tab cannot type an admin password or answer an OS permission prompt, so system installers (`brew`, `winget`, `.pkg`) would stall. The studio instead downloads portable, no-admin builds (Python via `uv`, a static ffmpeg, a portable Node) into `${CLAUDE_PLUGIN_DATA}`, after one plain-language question from the Diretor ("Posso preparar seu computador para editar vídeos? (~10 min, grátis)"). A `SessionStart` hook only checks and reports; it never installs silently. The cost is a 300–500 MB download and per-OS scripts we maintain; uninstalling the plugin removes everything.
